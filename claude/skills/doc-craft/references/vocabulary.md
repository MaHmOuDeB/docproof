# Vocabulary: verbs to use, filler to cut, AI tells to avoid

Word choice is one of the fastest ways a reader, human or software, judges whether a CV is
specific and credible or generic and inflated.

## Strong action verbs, by category

Open every bullet with one. Vary them: never three bullets in a row with the same opener.

| Category | Verbs |
|---|---|
| Leadership | Led, Directed, Managed, Coordinated, Supervised, Delegated, Championed, Mentored, Guided |
| Results | Delivered, Achieved, Exceeded, Secured, Won, Generated, Grew, Increased, Reduced, Cut |
| Creation | Built, Designed, Launched, Developed, Created, Established, Founded, Introduced |
| Efficiency | Streamlined, Optimized, Simplified, Automated, Restructured, Redesigned, Standardized |
| Analysis | Analyzed, Evaluated, Investigated, Assessed, Diagnosed, Modeled, Forecast, Audited |
| Communication | Presented, Authored, Drafted, Facilitated, Negotiated, Briefed, Trained, Advised |
| Collaboration | Partnered, Collaborated, Supported, Contributed, Liaised, Coordinated with |
| Commercial | Budgeted, Allocated, Priced, Reduced costs, Increased revenue |

Scope words carry claims. "Led", "owned", "built" and "designed" say the candidate did it
themselves; use them only where the fact base says so. Shared work gets "worked with",
"contributed to", "supported".

Pick one spelling system ("-ize" or "-ise") and keep it across the whole document.

## Generic filler: retire it

Not wrong, just empty: claims without evidence. Replace the claim with the proof.

| Instead of | Try |
|---|---|
| hardworking | dependable / consistent, or show it |
| team player | collaborated across [X] teams / partnered with |
| detail-oriented | caught / reduced errors by [X] |
| results-driven | delivered [specific result] |
| go-getter / self-starter | initiated / independently launched / proposed |
| responsible for | managed / led / ran |
| duties included | delete; start with a verb |
| passionate about | delete; show it through the result |
| dynamic | delete; describe the actual variety |
| excellent communication skills | presented [X] to [audience] / wrote [deliverable] |

## Words that read as AI-written

Common enough in generated text that recruiters and screening tools notice them. Even when the
candidate wrote the sentence, this vocabulary makes it read generated.

| Avoid | Use instead |
|---|---|
| delve into | explore / dig into |
| leverage | use / apply |
| spearheaded | led / launched / kicked off |
| foster | build / support / encourage |
| elevate | improve / raise |
| robust | reliable / thorough |
| seamless(ly) | smooth / without disruption |
| cutting-edge | new / recently adopted |
| unlock | enable / open up |
| holistic | complete / end-to-end |
| game-changer / game-changing | delete; let the number make the case |
| synergy / synergize | collaboration / worked together |
| boasts / showcases | has / includes |
| in today's fast-paced world | delete |
| utilize | use |
| moreover / furthermore | delete; start the next sentence directly |

For prose (summaries, cover letters) also strip: "I am excited", "I am passionate", "perfect
match", "exactly aligns", "world-class", "I firmly believe", "I have always admired your
company".

## Other habits to watch

- **Adjective stacks** ("a dynamic, detail-oriented, results-driven professional"): cut to one
  specific claim with a number behind it.
- **Em dashes and semicolons chaining clauses**: a strong AI tell. Prefer short sentences or a
  single colon. One dash pair in a document is fine; chains aren't.
- **Rhetorical framing** ("it's not just X, it's Y", "not X, but Y"): say the one true thing
  plainly.
- **Absolutes** ("expert", "world-class", "unparalleled"): they invite scrutiny; let the result
  carry the claim.
- **Metaphor openings** ("from spotting a gap to shipping the fix"): reads as copywriting. Lead
  with the identity and a fact.

## The final test

Could this word be swapped into anyone else's CV without changing its meaning? Then it's filler.
